03 模块一：光学与偏振 · 第 2 章

模块一平面叠层用 TMM 扫参，FDTD 做交叉验证和有限尺寸模型

A(λ, θ) = Ax(λ)·cos²θ + Ay(λ)·sin²θ
DR = Ax / Ay，ΔA = Ax − Ay
Gopt(z) = ½ωε₀ε″(z)|E(z)|² / ħω
条件：正入射、SnS 晶轴对齐 x/y、其余层面内各向同性 → x、y 偏振不耦合
扫描任务（TMM）
  1. 532、808 nm 下扫 t_SnS 10–100 nm × t_hBN 0–80 nm（步长 2 nm）→ 干涉吸收热力图
  2. G0 / G1 / 顶底双封装在 400–1200 nm 的吸收谱
  3. 特征波长下 |E(z)|² 与 G_opt(z) 深度分布
  4. A(θ) 极坐标、DR 与 ΔA 随厚度；按 ΔA / √(A_x + A_y) 选最优厚度
FDTD（Lumerical，校外可用）：① 3–5 个点与 TMM 交叉验证，误差 < 2%；② 有限尺寸模型：石墨烯电极边缘、SnS 片边缘与沟道区的场分布，给第 3 章用作光生载流子的空间分布
全部厚度网格约 2.5 万次运行交给 TMM，FDTD 只算关键结构
偏振吸收极坐标：两个数决定整条曲线
A(θ) 由 A_x、A_y 计算原手册的 FDTD 角度点（A_x、A_y 为示意值）
03 模块一：光学与偏振 · 第 2、5 章

模块一偏振前端：单器件最多提升 2 倍，改用正交器件对差分

单器件（强轴 ∥ 目标偏振）
S = Ip·Ax + Iu·(Ax + Ay)/2
非偏振背景吸收的是 (A_x + A_y)/2，不是 A_x/DR
对比度增益 ≤ 2·DR/(DR + 1) < 2
正交器件对差分
S∥ = Ip(Axcos²θ + Aysin²θ) + IuĀ
S⊥ = Ip(Axsin²θ + Aycos²θ) + IuĀ
D = S∥ − S⊥ = Ip(Ax − Ay)·cos2θ
Ā = (A_x + A_y)/2：背景项相减为 0，只剩两路噪声相加
SNRD = Ip·ΔA / √[(Ax + Ay)(Ip + Iu) + 2σr²]
散粒噪声 + 读出噪声（光电子计数）；背景占主导时 ∝ ΔA/√(A_x + A_y)，就是第 2 章选厚度的指标。对照组要加"普通探测器 + 外置偏振片"。
单器件对非偏振背景的对比度增益（解析式）
规律DR 再大，单器件的增益也不超过 2；SnS 的 DR 若在 1.5–3，只有 1.2–1.5 倍，所以改用差分。
04 模块二：器件与陷阱建模 · 第 3 章

模块二先把静电算对：阈值漂移要用 C_eff，符号跟俘获的载流子走

1/Ceff = tox/(ε₀εox) + thBN/(ε₀εhBN)
ΔVth = −Qt / Ceff；俘获电子时 Qt = −q·nt
⇒ ΔVth = +q·nt / Ceff（p 沟道电导上升 = 光写增强）
nGr = Ceff|Vg − VDirac| / q
ΔEF = sgn(Vg − VDirac)·ħvF√(πnGr)
ΦBp(Vg) = ΦBp0 + S·ΔEF，0 ≤ S ≤ 1
S 为钉扎因子，作为待定参数扫描；G0 的栅–石墨烯电容取 C_ox
数值例（300 nm SiO₂ + 20 nm h-BN，nt = 10¹² cm⁻²）
Cox ≈ 11.5 nF/cm²，ChBN ≈ 155 nF/cm² → Ceff ≈ 10.7 nF/cm²
ΔVth = q·nt/Ceff ≈ 15 V；用 ChBN 只得 1.0 V
  • I_ds：热电子发射 + 沟道串联电阻；计入 h-BN 串联电容后再比较 G0、G1
每 10¹² cm⁻² 俘获电子引起的阈值漂移
用 C_eff（正确）用 C_hBN（原手册）
规律电荷靠近沟道时，起作用的是栅极到电荷层的电容 C_eff。用 C_hBN 会把漂移低估约 15 倍，拟合出的缺陷密度差一个数量级。
04 模块二：器件与陷阱建模 · 第 3、4 章

模块二一个陷阱模型、两类陷阱，G0/G1/G2 只是三组参数

两类陷阱的能带示意（以光写 / 电擦为例）
dnk/dt = Rcap(t)·(Nk − nk) − nk / τk(Vg)
Rcap = σopt·A(λ, θ)·P(t)/hν（光写）+ kel(Vg)（电写，脉冲期间）
τk = τk0·exp(−s·β√|Eox|)，τk0 = ν₀⁻¹·exp(Ek/kBT)
s = +1 擦除极性（加速释放），s = −1 反向极性；n_t = Σ n_k，N_k 按 g(E_k) 分配。写入方式未定：方案 A 光写电擦、方案 B 电写光调，同一方程只换驱动项
G = μpCeff(W/L)·max(0, Vth0 + ΔVth − Vg,read)
两类陷阱的分工
  • 快陷阱 D_it（界面态，τ 短）→ 光栅控增益与响应时间（第 3 章）
  • 慢陷阱 N_t（h-BN 深缺陷，τ 长）→ 突触保持与非线性（第 4 章）
  • 能级分布自然给出拉伸指数保持：I(t) = I∞ + ΔI·exp[−(t/τ)β]
参数来源（避免拟合过度）
  • 取文献值：t_ox、ε、E_g、χ、μ_p、v_F
  • 校准得到：N_t 的能级分布 g(E)、σ_opt、β、τ_k0
  • 作为设计变量扫描：D_it、钉扎因子 S、t_hBN、脉冲宽度与功率
04 模块二：器件与陷阱建模 · 校准

模块二用 Fang 2023 校准，但先说清楚哪些参数能迁移

校准与验证流程
参数能否从 SnS₂ 迁移到 SnS
参数迁移说明
N_t、能级分布 g(E)可以同为 O₂ 等离子体 h-BN；处理条件不同需扫描
俘获截面、β谨慎与被俘获的载流子种类有关
载流子类型不能SnS₂ 为 n 型，SnS 为 p 型
能带对齐不能决定俘获的是电子还是空穴
光写项 A(λ, θ)不能Fang 用 820 nm（1.51 eV），低于 SnS₂ 带隙约 2.2 eV，是缺陷激发；SnS 在 820 nm 是带间吸收
迁移率、V_th0不能换用 SnS 文献值
写入方式还没定：方案 B（电写光调）与 Fang 2023 一致，可直接校准；方案 A（光写电擦）要外推光写项，作为预测给出。论文里写成"机制假设 + 情形分析"。摘要只提到 LTP，LTD 数据要先看原文图。
04 模块二：器件与陷阱建模 · 第 4 章

模块二突触指标、两种写入方案，以及送给网络的器件参数

PPF = A₂ / A₁ × 100%（随脉冲间隔 Δt 衰减）
保持：I(t) = I∞ + ΔI·exp[−(t/τ)β]
GLTP(n) = B(1 − e−n/Ap) + Gmin
GLTD(n) = −B(1 − e(n−nmax)/Ad) + Gmax
B = (Gmax − Gmin) / (1 − e−nmax/A)
送给网络的器件参数
  • 非线性度 (α_p, α_d)、G_max/G_min、可分辨电导级数
  • 周期间噪声（1%–5%）、推理前保持衰减
  • 两种写入方案（光写电擦 / 电写光调）都扫 N_t 与脉冲参数，按非线性、对称性、动态范围、保持时间选一种给第 5 章
突触指标
  • EPSC、PPF、STP → LTP 转变、保持（10³–10⁴ s）、多周期 LTP/LTD
  • 外推结果画虚线并标"预测"，校准用的文献数据画散点并注明出处
NeuroSim 更新公式示意
A = 8A = 60（A 为示例值，非仿真结果）
规律A 越小，前几个脉冲的电导变化越大、越非线性；网络准确率对这一点很敏感。
